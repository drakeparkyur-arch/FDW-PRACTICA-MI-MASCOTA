# MiMascota - Cuarta Práctica Calificada (Angular + Bootstrap)

Componentes: Cabecera (menú), Pie de Página (enlaces Perros y Peluquería).
Páginas: Nosotros (carrusel de 3 imágenes) y Servicios (plantilla Bootstrap).

1. Abrir la carpeta en Visual Studio Code.
2. `npm install`
3. `npm start`  -> http://localhost:4200

Para usar fotos reales en el carrusel, ponlas en `public/images` y cambia
las rutas en `src/app/paginas/nosotros/nosotros.component.ts`.
